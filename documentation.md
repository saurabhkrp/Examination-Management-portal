# 📐 Examination Management Portal (EMP) — System Wireframe & UI Flow Documentation

> **Project:** Examination Management Portal (EMP)  
> **Tech Stack:** Python (Flask), Jinja2, HTML5, Bootstrap 5, SQLite (SQLAlchemy)  
> **Architecture:** Role-Based Access Control (RBAC) — Admin, Examiner, Student

---

## 🧭 1. Master Navigation & Role Flow

```text
                        +-----------------------+
                        |   /login (Entry)      |
                        +-----------+-----------+
                                    |
         +--------------------------+--------------------------+
         |                          |                          |
         v (Admin)                  v (Examiner)               v (Student)
+--------+--------+       +---------+---------+      +---------+---------+
| Admin Dashboard |       | Approval Check?   |      | Student Dashboard |
| /admin/dashboard|       +----+---------+----+      | /student/dashboard|
+--------+--------+            | (No)    | (Yes)     +---------+---------+
         |                     v         v                     |
         |            [Pending Screen] [Examiner Dash]         |
         |                             /examiner/dashboard     |
         +-----------------------+---------------+-------------+
                                 |               |
         +-----------------------+               +-----------------------+
         | (Admin Sub-Views)                     | (Examiner/Student)    |
         |-- /admin/courses                      |-- /examiner/evaluate  |
         |-- /admin/exams                        |-- /student/exams      |
         |-- /admin/rubrics/<id>                 |-- /student/book/<id>  |
         |-- /admin/examiners                    |-- /student/results    |
         |-- /admin/slots                        |-- /student/profile    |
         +-- /admin/bookings
```

## ⚙️ 6. Core System Guardrails & Validation Rules

```text
+-----------------------------------------------------------------------+
|  SYSTEM GUARDRAILS & VALIDATION ARCHITECTURE                          |
+------------------------+-------------------+--------------------------+
| Rule / Constraint      | Enforcement Layer | System Behavior          |
+------------------------+-------------------+--------------------------+
| No JS Core Logic       | Frontend/Backend  | Pure HTML POST forms &   |
|                        |                   | server-side redirects.   |
+------------------------+-------------------+--------------------------+
| Programmatic DB        | init_db.py        | Tables & Admin seeded via|
|                        |                   | SQLAlchemy create_all(). |
+------------------------+-------------------+--------------------------+
| Slot Creation Window   | routes/examiner.py| Blocks slot creation     |
|                        |                   | outside start/end window.|
+------------------------+-------------------+--------------------------+
| Booking Window         | routes/student.py | Blocks booking/canceling |
|                        |                   | outside booking window.  |
+------------------------+-------------------+--------------------------+
| Anti-Overbooking       | routes/student.py | Decrements seats; marks  |
|                        |                   | status 'Full' at 0 seats.|
+------------------------+-------------------+--------------------------+
| Anti-Duplicate Booking | routes/student.py | Checks active booking for|
|                        |                   | (student_id, exam_id).   |
+------------------------+-------------------+--------------------------+
| Evaluation Isolation   | routes/examiner.py| Verifies examiner owns   |
|                        |                   | slot before grading.     |
+------------------------+-------------------+--------------------------+
```
